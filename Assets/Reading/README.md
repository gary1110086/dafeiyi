# 阅读与展示素材

两张内置阅读背景随本版本提供，经项目提供者确认可随软件分享；保留原图与底部文字。
`thinking-maid.png` 与 `angry-maid.webp` 是内置背景，窗口的渐变遮罩由程序绘制。
`whale-portrait.png` 是去掉文字和气泡的透明展示素材，`whale-app.ico` 为应用图标。
`edge-reveal.png` 为生成的八姿势透明动画序列，用于贴边探头。

阅读背景、生成展示素材与相关人物/商标权利，不应视为代码 MIT 许可的一部分。
Whale 目录内动画使用该目录自己的第三方许可及来源说明。自选背景由每位用户在本机自行配置，不随此发行包上传。
