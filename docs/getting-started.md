# 大肥译 · 一分钟上手

**简体中文** | [English](getting-started.en.md) · [返回首页](../README.md)

## 下载与安装

在 [最新版本](https://github.com/gary1110086/dafeiyi/releases/latest) 下载 Windows-x64 的 ZIP，完整解压。Source 是源码包。

双击「安装到桌面.cmd」添加桌面入口；需要开机启动则用「安装并开机启动.cmd」。无需卸载旧版，覆盖安装会保留本机配置、登录、历史、术语与背景。

## 先体验，再连接

打开 **设置 → 使用指南 → 体验划词示例**，选中示例中的一句英文并点翻译。本地示例不请求模型。

在 **连接与模型** 中二选一：

- **官网账号**：打开应用内官网登录，完成验证，点检查连接，页面就绪后返回浮窗。关闭账号窗口会保留登录。Chrome 或其他浏览器的登录不会同步到应用。
- **API**：填写自己的 API Key 并测试连接，保存后使用。费用计入自己的 API 账户；官网连接失败不会自动切换到 API。

## 读文字、公式和图片

先用「点击小按钮」模式：选中一段文字，点翻译或解释。单击肥鱼可随时改为自动、剪贴板或仅陪伴；按住拖动肥鱼调整位置。

选区读不到时，先复制再按 **Ctrl+Alt+V**；图片里的文字用 **Ctrl+Alt+S**。公式、曲线和示意图选择「框图 / 公式」，预览裁剪区域后再提交。

未固定的结果窗口点击其他软件会收起；**Esc** 也可收起。点图钉可保持显示，拖动边缘调整大小，**Aa** 调整字号和行距。点击收藏保存术语、个人笔记和常用译法。

## 遇到问题

| 表现 | 先检查什么 |
|---|---|
| 没有划词按钮 | 是否暂停或仅陪伴；当前软件是否提供文字选区；尝试复制或屏幕识字 |
| 官网翻译失败 | 登录是否在应用内完成；是否有验证、未发送草稿；检查连接后重试当前请求 |
| 官网窗口打不开 | 安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)；用浏览器辅助入口检查网络 |
| 快捷键没反应 | 可能被其他软件占用；使用肥鱼菜单的屏幕识字或翻译剪贴板入口 |
| 改名后无法更新 | 手动下载 v1.1.2 或更新版本并覆盖安装一次；以后可在「更新与关于」检查更新 |

仍有问题，使用 [问题反馈](https://github.com/gary1110086/dafeiyi/issues/new/choose)，提供应用版本、连接方式、模式、复现步骤和错误提示。官网窗口可导出连接诊断，不包含原文、账号、Cookie 或 API Key。

**不要提交密钥、密码、Cookie、个人设置文件或未经遮挡的私人截图。**自动和剪贴板模式会发送相应文字；复制私人内容前切换到点击或陪伴模式。
